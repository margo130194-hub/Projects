# Gravity Bank

Gravity Bank is a learning iOS application that simulates a mobile banking experience. The project was created to practice iOS development using UIKit, MVVM architecture, and REST API integration.

## Features

- User authentication
- Registration and login
- Display of bank deposits
- REST API integration
- JSON parsing with Codable
- Dark and Light Mode
- Responsive UIKit interface
- Displays ATMs using MapKit

## Technologies

- Swift
- UIKit
- MVP
- REST API
- URLSession
- Codable
- Auto Layout
- UserDefaults
- Keychain
- Git
- Notifications

## Purpose

This project was developed as part of an iOS development course to practice building a multi-screen application, working with networking, application architecture, and user interface design.
